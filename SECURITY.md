# Security Policy

conmon-rs follows the
[security policy of CRI-O](https://github.com/cri-o/cri-o/blob/main/SECURITY.md),
which covers vulnerabilities of conmon-rs as well.

If you think you found a security issue, do not report it publicly in an
issue, a pull request or a discussion. Send an email with the affected version,
how to reproduce the issue and its impact to the private
[cncf-crio-security@lists.cncf.io](mailto:cncf-crio-security@lists.cncf.io)
list. You can expect an initial response within 3 business days.

How known vulnerabilities of the dependencies get checked and assessed is
described in [release.md](release.md#vulnerabilities-and-vex-statements).
